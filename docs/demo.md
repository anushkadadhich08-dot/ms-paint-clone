# GraphiDraw Demonstration Flow

1. Open `index.html` in a modern browser.
2. Draw with Pencil and Brush; change the color and size.
3. Select DDA, draw a line, and enable algorithm details.
4. Select Bresenham and compare a second line.
5. Draw a Midpoint Circle, then a closed rectangle.
6. Use Flood Fill inside the rectangle.
7. Select an area, rotate, scale, and reflect it.
8. Undo and redo an operation.
9. Change zoom and verify the coordinate display.
10. Export PNG, then demonstrate opening a PNG/JPG image.
